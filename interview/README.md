# GenAI / LLM Interview Pack

Use **Problem → Architecture → Trade-off → Failure Mode → Mitigation → Metric**.

## Core topics
- Tokens, context, attention and decoding
- Prompt engineering and instruction hierarchy
- Embeddings, chunking, retrieval and reranking
- RAG evaluation and hallucination control
- Tool calling, agent loops, state and memory
- MCP and tool permissions
- Structured outputs and schema validation
- Prompt injection and data exfiltration
- Latency, throughput, token economics and caching
- Model routing, fallbacks and fine-tuning vs RAG
- Production architecture and observability

## Practice
For every project answer: Why this architecture? What breaks at 10x traffic? What breaks with malicious input? How do you measure quality? What changes if cost doubles?
