# 21. RAG Q&A API

## Goal
Build a production-oriented RAG capability with explicit retrieval and answer-quality evaluation.

## Build
- [ ] Ingest and parse documents
- [ ] Design chunking and metadata
- [ ] Implement retrieval and grounded generation
- [ ] Add citations and abstention behavior
- [ ] Build a golden evaluation set
- [ ] Measure retrieval quality, answer quality, latency and cost
- [ ] Document hallucination and stale-data failure modes

## Interview
Explain retrieval failure modes, grounding, reranking, query rewriting, access control and how you prevent unsupported answers.

## Stretch
Add hybrid search, reranking, query routing, caching and tracing.
