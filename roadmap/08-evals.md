# Stage 8: Evaluation & Observability

## Learn
Focus on **golden datasets, judges, task metrics, tracing, latency, tokens and cost telemetry**.

## Practice loop
1. Read official documentation and one conceptual guide.
2. Reproduce one concept without a framework.
3. Build a small experiment and measure it.
4. Compare two design choices.
5. Record failure modes and mitigations.

## Exit criteria
- [ ] Explain the concept without a framework
- [ ] Implement a minimal version
- [ ] Test quality and failure modes
- [ ] Explain latency, cost and security implications
- [ ] Connect it to a production architecture
